# 虚拟博物馆展厅平台

一个纯前端的 3D 虚拟展厅创建和分享平台，无需编程即可创建、自定义并分享沉浸式虚拟展厅。

## 功能特性

- **零编程门槛**：可视化操作，无需代码知识
- **3 种博物馆模板**：古典博物馆、现代美术馆、历史考古风格
- **展品管理**：上传 JPG/PNG 图片，添加名称和描述
- **AI 辅助布局**：智能分配展品到墙面和展台位置
- **拖拽编辑**：手动调整展品位置、旋转和缩放
- **第一人称漫游**：WASD 移动 + 鼠标拖拽视角
- **URL 分享**：展厅数据编码到 URL 哈希中，直接分享链接
- **本地存储**：草稿自动保存到浏览器 LocalStorage

## 技术栈

- **3D 引擎**：Three.js r150.1
- **数据压缩**：LZ-String
- **纯前端**：HTML + CSS + JavaScript，无后端依赖

## 使用方法

### 1. 创建展厅

1. 打开 `index.html`
2. 选择展厅模板（古典博物馆、现代美术馆、历史考古）
3. 进入编辑器页面

### 2. 上传展品

1. 点击左侧"上传展品"按钮
2. 拖拽或选择图片文件（JPG/PNG，最大 5MB）
3. 填写展品名称和描述
4. 选择展品类型（墙面挂画或展台陈列）
5. 点击"确认添加"

### 3. 编辑布局

- **AI 布局**：点击"AI 布局"按钮自动排列展品
- **手动拖拽**：在 3D 场景中拖拽展品调整位置
- **属性编辑**：点击展品后在右侧面板调整位置、旋转、缩放
- **删除展品**：在属性面板点击"删除展品"

### 4. 保存和分享

- **保存**：点击"保存"按钮保存到本地浏览器
- **预览**：点击"预览"在新窗口查看漫游效果
- **分享**：点击"分享"生成 URL 链接，复制后发送给他人

### 5. 漫游控制

| 按键 | 功能 |
|------|------|
| W / ↑ | 向前移动 |
| S / ↓ | 向后移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 鼠标移动 | 旋转视角 |
| ESC | 显示/隐藏鼠标 |

## 注意事项

1. **URL 长度限制**：分享链接长度限制约 2000 字符，大型展厅可能无法完整编码
2. **图片大小**：单张图片最大 5MB，建议压缩后上传
3. **本地存储**：草稿保存在浏览器 LocalStorage，清除缓存会丢失
4. **跨域问题**：由于使用 CDN 加载 Three.js，需要联网使用

## 本地运行

直接双击打开 `index.html` 即可使用，或使用本地服务器：

```bash
# 使用 Python 简单服务器
python -m http.server 8000

# 或使用 Node.js 的 http-server
npx http-server -p 8000
```

然后在浏览器访问 `http://localhost:8000`
